# Global-Airbnb-Dashboard-Power-bi-
Power BI dashboard analyzing global Airbnb market share, pricing, ratings, and listing lifecycle trends (2008–2021).
This dashboard analyzes Airbnb listings across major global cities to uncover market shifts, pricing by room type, hosts (Superhost vs non-Superhost), and how new listing growth has evolved from 2008 to 2021 across different stages (Introduction, Growth, Maturity, Reinvention, Decline).
